Sprite QA Lightbox

Every sprite in catalog.js / OBJECTS.md, shown exactly as the game will load it: the masked PNG from sprites/.

How to review, and how the agent uses the result
  1. Filter by sheet, class or search. Switch the preview background (checker / grass / sand / dark) to spot stray or missing edge pixels.
  2. Click a card. Left: the sprite enlarged with its anchor (red cross = foot point used for placement and depth sorting). Below: the source sheet dimmed, with this sprite's own pixels lit and its box outlined — anything lit that is not this object is a masking error.
  3. Check: whole object present (incl. its shadow); no neighbour pixels; anchor at the base of the trunk/body; class, name and description correct.
  4. Mark OK, Fix (write what is wrong in the note) or Drop (not useful as a game object). Keys in the dialog: ← → navigate, O / F / D mark.
  5. Export QA downloads tiles-qa.json (schema tiles-qa/2). Give it to the agent.

For the agent: this page is read-only. Join on id. For fix entries, change the segmentation masks or labels as the note says and regenerate sprites, atlas, catalog and OBJECTS.md; remove drop entries from the catalog. Never hand-edit atlas coordinates.
